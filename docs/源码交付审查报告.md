## 交付内容与隐私边界

本包只含源码、必要图片资源、标准 Gradle wrapper、示例配置与文档。不含 APK/AAB、生产 .env、账号 JSON、SSH 私钥、真实签名库、local.properties、日志、备份、运行快照、Git 历史、构建缓存。

基础 .env.example 的访问 Token、主机地址为 CHANGE_ME 占位符；可选认证与地址为空。Compose 为通用模板，GitHub Actions 仅引用接收方自己的 Secrets 名称。root/admin 等厂商或系统通用默认用户名不是作者账户凭据。

曾发现的账号昵称/ID、注释邮箱、内网测速地址、设备实体指纹、个人网络注释已清除或配置化。知识库工作区由接收方后端配置统一决定。所有修改均作用于交付副本，原部署源码未由本次任务修改。

允许保留的公开信息：SDK/Gradle/GitHub 等公开依赖域名、厂商公开 API 域名、RFC 示例域名、loopback 地址与中性测试 Token。它们不属于作者的域名或秘密。
